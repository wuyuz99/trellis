# home-repo — Sam's personal context

This is my Home Repo: my skills, shared docs and personal context. Code lives in its own repos.

**Who:** backend developer. Code repos: `orders-api` (exports, billing), `web` (dashboard).
**Style:** terse, explain the why, small PRs. Details → `references/style.md`
**Task backend:** none (notes only). Push allowed: no.

## Map (read only what you need)
- `skills/`: my own skills (one folder each, SKILL.md inside).
- `tasks/active.md`: current priorities. `tasks/<task>.md`: why/decisions/gotchas/next.
- `tasks/backlog.md`: inactive work. `tasks/archive/`: closed tasks.
- `journal/YYYY-MM-DD.md`: append-only session log.
- `references/style.md`, `references/lessons.md`: style and cross-task gotchas.
- `meta/pattern-log.md`: how this system is working.

## Conventions
- Start of day: end the summary with exactly one line starting `Today's one thing:` naming the single most important next action.

## Rules
- No secrets, credentials, hostnames/IPs or customer data.
